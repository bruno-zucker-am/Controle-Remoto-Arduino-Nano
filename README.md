# Controle-Remoto-Arduino-Nano
Simulação de controle remoto infravermelho com Arduino Nano no Wokwi. Ao receber um comando (IRremote), o código em C++ mostra o valor HEX no Monitor Serial, pisca um LED e mede a distância com sensor ultrassônico HC-SR04. Desenvolvida como parte de um portfólio prático de sistemas embarcados.
